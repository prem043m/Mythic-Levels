# Human-Labelled Dataset — V1 Submissions

## Dataset status

These are the 20 submissions for the Discipline Challenge pilot. They are **not yet human-labelled**; record blind human decisions and scores in `HUMAN_EVALUATION_RESULTS_V1.md`.

The cases target the fixed quest and five-field format in `HUMAN_EVALUATION_GUIDE.md`. The current V5 Compass Gate does not contain that Challenge stage. Do not submit these cases to a different stage or a normal player profile.
